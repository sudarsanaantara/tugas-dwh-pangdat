# Dokumentasi Proyek Data Warehouse — BikeStores

Dokumentasi ini disusun bertahap agar setiap keputusan desain, proses pengolahan data, dan hasil implementasi dapat ditelusuri dengan jelas.

## Struktur Dokumentasi

```text
bikestore_dwh_docs/
├── README.md
├── 00_project_overview.md
├── 01_business_process.md
├── 02_dwh_design.md
└── 03_oltp_to_dwh_mapping.md
```

Dokumen berikutnya akan ditambahkan setelah tahap tersebut benar-benar dikerjakan:

```text
04_data_profiling.md
05_data_quality_checklist.md
06_data_cleansing.md
07_etl_design.md
08_etl_implementation.md
09_validation_testing.md
10_scheduler_automation.md
11_results_and_findings.md
FINAL_REPORT.md
```

## Prinsip Dokumentasi

Setiap tahap menggunakan pola yang konsisten:

1. **Tujuan**
2. **Input**
3. **Proses**
4. **Keputusan**
5. **Hasil**
6. **Validasi**
7. **Catatan / Temuan**
8. **Status**

> Dokumentasi teknis dibuat per tahap. `FINAL_REPORT.md` akan disusun setelah semua tahap selesai sebagai ringkasan final proyek.
